\href{https://www.glfw.org/}{\texttt{GLFW}} は \href{https://www.opengl.org/}{\texttt{Open\+GL}} や、その後継の \href{https://www.vulkan.org/}{\texttt{Vulkan}} を使用したアプリケーションを作成するための、非常にコンパクトなフレームワークです。本当はこれだけで簡単にアプリケーションが作れるのですが、授業内容とはあまり関係のない処理を分離するために、屋上屋ながら\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}この授業専用の\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}フレームワークを用意しました。なお、gg.h / \doxylink{gg_8cpp}{gg.\+cpp} には Open\+GL の拡張機能を使用可能にする機能を含んでいるので、別に \href{http://glew.sourceforge.net/}{\texttt{GLEW}} や \href{https://github.com/Dav1dde/glad}{\texttt{glad}}、\href{https://github.com/skaslev/gl3w}{\texttt{GL3W}} などを導入する必要はありません。

また、この補助プログラムは \href{https://github.com/ocornut/imgui}{\texttt{Dear Im\+Gui}} をサポートする機能を含んでいます。このプログラム (\href{https://github.com/tokoik/ggsample01}{\texttt{ggsample01}}) には、その使い方のサンプルコードを示すために、\+Dear Im\+Gui のソースプログラムも含めています。日本語メニューの表示のために \href{https://mplusfonts.github.io/}{\texttt{M+ FONTS}} の \href{https://github.com/coz-m/MPLUS_FONTS/blob/master/fonts/ttf/Mplus1-Regular.ttf}{\texttt{Mplus1-\/\+Regular.\+ttf}} もリポジトリに含めています。

このほか、この \doxylink{GgApp_8h}{Gg\+App.\+h} / \doxylink{GgApp_8cpp}{Gg\+App.\+cpp} には \href{https://www.khronos.org/openxr/}{\texttt{Open\+XR}} をサポートする機能を組み込んでいます。\+Meta Quest 2 / 3 / 3S / Pro や HTC Vive、\+Valve Index 等の VR デバイスを接続しているなら、この補助プログラムを使って C++ だけで VR アプリケーションが作成できます。\hypertarget{md_README_autotoc_md80}{}\doxysubsection{\texorpdfstring{補助プログラムのドキュメント}{補助プログラムのドキュメント}}\label{md_README_autotoc_md80}
