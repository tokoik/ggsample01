\hypertarget{md_OPENXR_autotoc_md4}{}\doxysection{\texorpdfstring{1. 概要と特徴}{1. 概要と特徴}}\label{md_OPENXR_autotoc_md4}
{\ttfamily Gg\+App\+::\+Open\+XR} は、業界標準の XR 規格である {\bfseries{\href{https://www.khronos.org/openxr/}{\texttt{Open\+XR}}}} を用いて、\+Open\+GL による VR アプリケーションを極めてシンプルかつ直感的に開発できるように設計された C++ ラッパークラスです。\hypertarget{md_OPENXR_autotoc_md5}{}\doxysubsection{\texorpdfstring{主な特徴}{主な特徴}}\label{md_OPENXR_autotoc_md5}

\begin{DoxyItemize}
\item {\bfseries{{\ttfamily \doxylink{gg_8h}{gg.\+h}} 数学ライブラリとのシームレスな統合}}\+:
\begin{DoxyItemize}
\item {\ttfamily get\+Projection\+Matrix(eye, z\+Near, z\+Far)} を呼ぶだけで、\+HMD 特有の非対称視野角（\+Off-\/\+Center Frustum）に対応した正確な透視投影変換行列 ({\ttfamily Gg\+Matrix}) を直接取得できます。
\item {\ttfamily get\+View\+Matrix(eye)} により、\+HMD の頭部トラッキング姿勢からワールド座標系に対するビュー変換行列 ({\ttfamily Gg\+Matrix}) を 1 行で取得できます。
\end{DoxyItemize}
\item {\bfseries{標準化されたコントローラー（入力・トラッキング）の統合サポート}}\+:
\begin{DoxyItemize}
\item Meta Quest Touch、\+HTC Vive、\+Valve Index、\+Windows Mixed Reality などの主要な VR コントローラーを標準でサポート。
\item 手のグリップ姿勢 ({\ttfamily get\+Grip\+Matrix})、エイム（ポインティング）姿勢 ({\ttfamily get\+Aim\+Matrix})、各種ボタン（\+Trigger, Grip, Thumbstick, Primary/\+Secondary, Menu）やハプティクス振動を即座に利用可能。
\end{DoxyItemize}
\item {\bfseries{シンプルなフレームライフサイクル}}\+:
\begin{DoxyItemize}
\item {\ttfamily begin()} -\/\texorpdfstring{$>$}{>} {\ttfamily select(eye)} -\/\texorpdfstring{$>$}{>} {\ttfamily commit(eye)} -\/\texorpdfstring{$>$}{>} {\ttfamily submit(mirror)} の分かりやすいループ構成。\+FBO バインド、スワップチェーン管理、ビューポート設定、s\+RGB カラースペース処理を内部で自動処理。
\end{DoxyItemize}
\item {\bfseries{柔軟な空間座標系}}\+:
\begin{DoxyItemize}
\item ルームスケール・床面基準の {\ttfamily XR\+\_\+\+REFERENCE\+\_\+\+SPACE\+\_\+\+TYPE\+\_\+\+STAGE} と、着席・頭部原点基準の {\ttfamily XR\+\_\+\+REFERENCE\+\_\+\+SPACE\+\_\+\+TYPE\+\_\+\+LOCAL} に両対応。
\end{DoxyItemize}
\end{DoxyItemize}
